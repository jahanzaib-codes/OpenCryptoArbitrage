# 📝 Changelog

All notable changes to **OpenCryptoArbitrage** will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.1] - 2026-11-11
### Added
- Continuous integration GitHub Actions workflow with Python 3.10 and 3.11 test matrix.
- Institutional governance documentation: `CONTRIBUTING.md` and `SECURITY.md`.
- Structured version changelog.

## [1.0.0] - 2026-11-08
### Added
- Initial institutional release of Cross-Exchange Funding Rate & Spatial Arbitrage Engine.
- Real-time funding rate basis tracking and delta-neutral cash-and-carry alerts.\n- Cross-exchange spatial price discrepancy detection with fee-aware calculation.\n- Sub-second orderbook depth analysis and liquidity filtering.\n- Docker container deployment for continuous cloud monitoring.
